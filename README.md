# 🏋️‍♂️ PowerLog - Spor Takip Paneli

Bu proje, spora yeni başlayanlar için antrenman gelişimlerini takip edebilecekleri modern bir web dashboard uygulamasıdır.

## 🚀 Teknolojiler
- **Backend:** Python (Flask)
- **Veritabanı:** MySQL
- **Frontend:** HTML5, Bootstrap 5, Chart.js

## 🛠️ Özellikler
- Antrenman verisi girişi ve listeleme.
- Grafiksel gelişim takibi.
- Modern Dark Mode tasarımı.
